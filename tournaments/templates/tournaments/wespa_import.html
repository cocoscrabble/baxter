Import WESPA ratings

Upload a CSV of WESPA ratings to refresh the roster. A WESPA rating is only used for a player who has no CoCo rating, and it is never sent to the central database — it is Baxter's own copy of somebody else's number.

This does not disturb any tournament in progress: entrants pin the rating they were seeded from when they enter, so a refresh cannot reshuffle pairings.

File format

Two columns, name, rating, or three, player number, name, rating. A heading row is optional.

0233,Dave Wiegand,1842
0517,Alec Sjoholm,1795

Importing the CoCo roster is a separate thing — that upload sets names and CoCo ratings.

A player number matches exactly. A bare name matches only if exactly one player has it — a name shared by several players updates none of them and is reported, because the file cannot say which one it means.
